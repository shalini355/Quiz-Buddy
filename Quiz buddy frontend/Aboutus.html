About Quiz Buddy

An interactive coding assessment platform created to help learners strengthen core programming fundamentals through real-time feedback and structured challenges.

The Project Journey

Quiz Buddy was created in the first year of an undergraduate computer science engineering degree. Conceived as a tool to bridge theoretical programming coursework with active recall, the project explored how web technologies can transform study sessions into motivating quiz challenges.

Now in its senior iteration, Quiz Buddy has undergone a comprehensive audit and redesign. It has been refined into a professional product design case study focusing on usability, client-side resilience, accessibility compliance (WCAG AA), responsive layout systems, and zero-friction entry through Guest Mode.

Core Product Pillars

Frictionless Access

Immediate quiz participation with a dedicated Guest Mode. No mandatory registrations or email barriers to start testing your skills.

Actionable Feedback

Every question provides instant evaluation accompanied by clear explanations, enabling users to learn from mistakes immediately.

Privacy & Transparency

All quiz history and user statistics are stored transparently in browser storage without third-party tracking or data monetization.

Architecture & Technology

Quiz Buddy is engineered with lightweight, standards-compliant web technologies designed for instant loading, high maintainability, and universal cross-device accessibility:

Semantic HTML5 CSS3 & Bootstrap 4 Grid Vanilla JavaScript (ES6+) Client-Side LocalStorage WCAG AA Accessible Fully Responsive
